# PCB 결함 유형 분류

공개 PCB 이미지에서 단선·단락 등 6가지 결함을 분류하고, 모델이 자주 혼동하는 유형을 분석했습니다. 결함별 분류 성능을 비교해 추가로 검토해야 할 항목을 찾는 데 중점을 두었습니다.

| 분석 대상 | 사용 도구 | 주요 결과 |
|---|---|---|
| 이미지 693장, 결함 영역 2,953개 | Python, scikit-learn, scikit-image | 분류 정확도 89.0%, Macro F1 0.891 |

## 분석 과정

먼저 이미지의 주석에서 결함 위치와 유형을 읽어 결함 영역을 추출했습니다. 영역의 크기가 서로 달라 64×64로 맞춘 뒤, 너비·높이·밝기 등 9개 특징과 윤곽의 방향을 나타내는 HOG 특징 36개를 계산했습니다.

학습 데이터 2,214개와 평가 데이터 739개로 나누고, 각 결함 유형의 비율을 유지한 상태에서 Random Forest와 SVM을 비교했습니다. 전체 정확도와 함께 유형별 재현율과 F1 점수를 확인했습니다.

## 결과와 오분류 분석

| 모델 | 평가 정확도 | Macro F1 |
|---|---:|---:|
| Random Forest | 87.4% | 0.874 |
| SVM | 89.0% | 0.891 |

SVM의 성능이 더 높았으며, 단선과 단락의 재현율은 각각 95.9%, 92.7%였습니다. 반면 돌기(Spur)는 F1 점수 0.783으로 상대적으로 구분하기 어려웠습니다. Macro F1은 각 결함 유형의 F1 점수를 같은 비중으로 평균한 값입니다.

![SVM의 결함 유형별 분류 결과](results/confusion_matrix.svg)

혼동행렬을 확인한 결과, 마우스바이트(Mouse bite)와 동박 잔류(Spurious copper)를 돌기로 잘못 분류한 사례가 각각 14건으로 가장 많았습니다. 이 결과를 바탕으로 돌기와 주변 유형을 구분하는 경계 형태를 더 자세히 살펴볼 필요가 있다고 판단했습니다. 후속 분석에서는 이미지 해상도와 경계 곡률 특징을 바꿔 분류 성능을 비교할 수 있습니다.

이 과정에서 전체 정확도가 높더라도 특정 유형에는 오분류가 집중될 수 있다는 점을 확인했습니다. 검사 결과를 검토할 때 유형별 성능과 실제로 틀린 사례를 함께 확인하는 것이 중요했습니다.

## 평가 조건

결함 위치가 주어진 영역의 **유형 분류**를 평가했습니다. 전체 보드에서 결함을 찾거나 정상·불량을 판정한 결과와는 구분됩니다. 결함 영역 단위로 데이터를 나눴기 때문에 같은 이미지의 일부 영역이 학습과 평가에 함께 포함될 수 있습니다. 새로운 보드에 적용할 성능은 보드 단위 분할과 별도의 최종 평가 데이터로 확인할 필요가 있습니다.
