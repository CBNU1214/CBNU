# 김진성 | 품질 데이터분석 포트폴리오

전자공학 기반으로 **결함 유형을 구분하고, 검사 검출력을 검증하며, 품질 데이터의 이상 패턴을 분석**한 개인 프로젝트입니다. 공개 데이터·벤치마크·시뮬레이션을 사용했으며, 실제 방산 제품의 검사 또는 양산 개선 실적을 의미하지 않습니다.

## 대표 프로젝트

| 프로젝트 | 분석 과정 | 확인한 결과 | 품질관리와의 연결 |
|---|---|---|---|
| **[01. PCB 결함 유형 분류](pcb-defects/)** | 주석 영역 추출 → 특징 설계 → 모델 비교 → 오분류 분석 | SVM 정확도 **89.0%**, Macro F1 **0.891** | 단선·단락 등 결함 유형 판단, 유형별 분류 성능 점검 |
| **[02. ISCAS85 회로 결함진단](circuit-faults/)** | 정상/결함 출력 비교 → 검출률 산출 → 소형 회로 전수 검증 | 6종 회로, **3,774개** 단일 stuck-at 결함, c17 대상 결함 검출률 **100%** | 검사 패턴의 검출 범위와 미검출 항목 확인 |
| **[03. 제조공정 품질분석](manufacturing-defects/)** | 가상 p-관리도 → 관련 변수 탐색 → 모델 시나리오 비교 | **3,240건** 분석, ROC-AUC 약 **0.797** | 통계적 품질관리 실습, 원인조사 가설과 개선 검증 계획 수립 |

각 프로젝트에는 **코드, 결과 JSON, 시각화, 실행 방법, 해석 범위**를 함께 제공합니다.

## 읽는 순서

1. 각 프로젝트 README의 ‘문제와 접근’을 통해 분석 목적과 과정을 확인합니다.
2. 결과표·그림과 `results/`의 수치를 대조합니다.
3. 코드와 ‘해석 범위’를 통해 결과가 어떤 조건에서 성립하는지 확인합니다.

## 구성과 실행

Python 3.11~3.12 환경을 권장합니다. 저장소를 내려받은 뒤 이 폴더에서 의존성을 설치합니다.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Windows에서는 `.venv\Scripts\activate`로 가상환경을 활성화합니다. 이후 각 프로젝트 폴더로 이동해 README에 적힌 순서로 실행합니다. 원본 데이터는 각 배포처에서 내려받아 배치합니다. 모델 학습은 데이터 준비와 별도 단계입니다.

한국어 분석 그래프를 생성하려면 AppleGothic, 맑은 고딕, Noto Sans CJK KR, 나눔고딕 중 하나가 필요합니다. 제공된 영문 SVG 요약 그림은 한글 폰트 없이 열 수 있습니다.
