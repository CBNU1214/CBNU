# ISCAS85 회로 결함진단

회로에 결함이 생겼을 때 검사 입력으로 이를 검출할 수 있는지 확인했습니다. 공개된 ISCAS85 회로 6종을 대상으로 정상 출력과 결함 출력을 비교하고, 검사 입력 수에 따른 검출률과 미검출 항목을 분석했습니다.

| 분석 대상 | 사용 도구 | 주요 결과 |
|---|---|---|
| 조합회로 6종, 단일 결함 3,774개 | Python, NumPy, 구조적 Verilog 넷리스트 | 3,696개 검출, 78개 미검출 |

## 검사 방법

Verilog 넷리스트에서 게이트 연결 관계를 읽고, 앞단의 계산 결과가 다음 게이트로 전달되는 순서에 맞춰 시뮬레이션을 구성했습니다. 입력과 게이트 출력의 신호가 0 또는 1로 고정되는 stuck-at 결함을 하나씩 적용했습니다.

각 회로에 무작위 검사 입력 1,000개를 넣어 정상 회로와 결함 회로의 출력을 비교했습니다. 출력이 달라진 경우를 검출로 기록하고, 결함별 최초 검출 시점과 끝까지 검출되지 않은 항목을 남겼습니다.

## 검증 과정

결함을 주입하는 시점이 잘못되면 검사 입력을 충분히 넣어도 결과를 신뢰하기 어렵습니다. 따라서 입력 결함은 게이트 계산 전에 반영하고, 내부 신호의 결함은 후속 게이트로 전달되기 전에 적용되는지 점검했습니다.

입력이 5개인 c17 회로에는 가능한 조합 32개를 모두 적용했습니다. 이를 통해 정의한 결함 22개가 전부 검출되는지 확인했습니다. 정상 출력도 별도의 논리식으로 계산해 32개 입력에 대해 대조했습니다.

## 결과

| 회로 | 결함 수 | 검사 입력 1,000개 적용 후 검출률 | 미검출 수 |
|---|---:|---:|---:|
| c17 | 22 | 100.00% | 0 |
| c432 | 414 | 99.28% | 3 |
| c499 | 430 | 100.00% | 0 |
| c880 | 766 | 97.91% | 16 |
| c1355 | 1,118 | 99.55% | 5 |
| c1908 | 1,024 | 94.73% | 54 |
| 합계 | 3,774 | 97.93% | 78 |

![회로별 결함 검출률](results/coverage.svg)

같은 수의 검사 입력을 적용해도 회로별 검출률에는 차이가 있었습니다. 특히 c1908에서는 54개 결함이 검출되지 않아 추가 검사 패턴을 검토할 대상으로 구분했습니다. 무작위 검사에서 검출되지 않았다는 사실만으로 해당 결함을 검출 불가능하다고 판단하지 않았습니다.

이 프로젝트에서는 검출률을 계산하는 것과 함께 검사 절차가 올바르게 동작하는지 확인했습니다. 작은 회로의 전수 검사 결과를 대조하고, 미검출 항목을 따로 기록해 검사 범위를 구체적으로 확인할 수 있었습니다.

## 검사 범위

Python 논리 시뮬레이션으로, 1차 입력과 게이트 출력에 정의한 단일 stuck-at 결함을 평가했습니다. 검출률은 이 결함 집합을 기준으로 계산했으며, 실제 보드의 고장이나 지연·분기별 결함까지 평가한 수치는 아닙니다.
