# 실행 검증 기록

검증일: 2026-09-13

## 검증 환경

Python 3.12, NumPy 2.3.5, pandas 2.2.3, scikit-learn 1.8.0, matplotlib 3.10.8, seaborn 0.13.2 환경에서 확인했습니다. 원본 프로젝트의 정확한 패키지 버전 기록은 없어 라이브러리 차이에 따른 소수점 수준의 변화를 구분했습니다.

| 프로젝트 | 수행한 확인 | 결과 |
|---|---|---|
| PCB | 원본에 저장된 2,953×45 특징 배열과 라벨로 동일 분할·하이퍼파라미터를 적용해 SVM/RF 재학습 | SVM 정확도 0.8903924222, Macro F1 0.8907646257로 원본과 일치. RF 정확도 0.8741542625 일치; RF Macro F1은 원본 0.8740597114, 재실행 0.8740797849로 미세 차이 |
| ISCAS85 | 원본 넷리스트 6개에 1,000개 벡터씩 결함 시뮬레이션 재실행 | 3,774개 결함 중 3,696개 검출, 78개 미검출. 회로별 수치가 원본과 일치 |
| c17 | 32개 입력 전수 결함 검사 및 파서와 별도의 논리식으로 정상 출력 대조 | 정의한 22개 결함 검출률 100%, 32개 입력의 정상 출력 일치 |
| 제조공정 | 원본 CSV 3,240건으로 분석 스크립트 전체 재실행 | AUC: 원본 0.7965998475, 재실행 0.7971917722. 관리도 이탈 구간·관측 그룹 비율 일치 |
| 파일 | Python 구문 검사, JSON 파싱, Markdown의 로컬 링크 대상 존재 확인 | 통과 |

제조공정 고시간 그룹의 시나리오 예측은 원본 0.9580674950 → 0.7374815312, 재실행 0.9579969778 → 0.7377149093입니다. 재실행 수치를 원본 실행 결과로 덮어쓰지 않고 별도 결과 파일로 보존했습니다. 차이의 구체적 원인은 이번 검증에서 분리 규명하지 않았습니다.

## 검증하지 않은 범위

- PCB의 원본 이미지/XML에서 특징을 추출하는 단계는 재실행하지 않았습니다. 저장된 특징 배열 이후의 학습·평가 단계만 재실행했습니다. 이미지의 그룹 중복 여부도 확인하지 않았습니다.
- 실제 PCB 정상/불량 검사, 결함 위치 검출, 실물 회로 및 방산 제품의 성능을 검증하지 않았습니다.
- 제조공정 변수 치환은 예측 모델의 민감도 확인이며, 인과적 개선 효과·공정 개입 효과·현장 관리 기준을 검증하지 않았습니다.
- 실제 MSA, 검사 장비 교정, 규격 적합성 및 장기 신뢰성 검증 실적을 의미하지 않습니다.
