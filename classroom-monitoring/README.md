# 실시간 강의실 감시 카메라

카메라 영상에서 사람의 자세와 주변 물체를 감지하고, 설정한 행동이 일정 시간 지속되면 화면과 경고음으로 알리는 캡스톤 디자인 프로젝트입니다. 감지 화면과 학생별 알림, 출석·이탈 이미지 기록을 하나의 웹 화면에서 확인하도록 구성했습니다.

| 구분 | 내용 |
|---|---|
| 영상 처리 | Python, OpenCV, NumPy |
| 사람·자세 감지 | YOLOv8 Pose |
| 휴대전화·모자 감지 | YOLO-World |
| 얼굴 특징점 분석 | MediaPipe Face Detection, Face Mesh |
| 웹 화면·영상 전송 | Streamlit, streamlit-webrtc, PyAV |

## 주요 기능

| 기능 | 구현 방식 |
|---|---|
| 실시간 영상 표시 | 브라우저 카메라 영상을 받아 감지 결과를 겹쳐 표시 |
| 눈 감김 감지 | 눈 주변 특징점으로 눈의 가로·세로 비율(EAR)을 계산 |
| 고개 방향에 따른 알림 | 코와 얼굴 중심 사이의 거리를 기준으로 판단 |
| 턱 괴기 감지 | 손목과 턱의 위치를 비교 |
| 휴대전화·모자 감지 | YOLO-World로 찾은 물체가 사람 영역 안에 있는지 확인 |
| 경고 표시 | 행동별 감지 점수를 누적해 기준을 넘으면 알림과 경고음 출력 |
| 출석·이탈 기록 | 일정 기간 감지된 위치에 ID를 부여하고 이미지를 저장, 해당 위치에서 사람이 계속 감지되지 않으면 이탈 기록으로 이동 |

학생 ID는 영상 속 위치를 관리하기 위한 번호입니다. 얼굴을 대조해 이름이나 학번을 확인하는 방식은 아닙니다. 화면의 주의집중 알림도 얼굴의 위치 관계를 이용한 규칙이며, 실제 집중 상태를 측정하는 값은 아닙니다.

## 구현 과정

### 얼굴 크기에 따른 판단 기준 조정

같은 자세라도 카메라와의 거리에 따라 영상에서 보이는 얼굴 크기가 달라집니다. 손목과 턱 사이의 거리나 코의 위치를 고정된 픽셀 값으로 판단하면 가까운 사람과 먼 사람에게 같은 기준을 적용하기 어려웠습니다.

코드에서는 얼굴 영역의 크기에 비례해 턱 괴기와 고개 방향의 거리 기준을 조절하도록 구성했습니다. 기준값이 지나치게 작거나 커지지 않도록 최솟값과 최댓값도 설정했습니다. 관련 계산은 `calculate_adaptive_threshold()`에서 확인할 수 있습니다.

### 감지 결과 누적

한 프레임의 결과만으로 경고가 발생하지 않도록 행동별 점수를 누적했습니다. 해당 행동이 감지되면 점수를 올리고, 감지되지 않으면 점수를 낮춥니다. 점수가 설정된 기준에 도달하면 경고를 표시하고, 다시 기준 아래로 떨어지면 경고를 해제합니다.

점수는 처리한 프레임을 기준으로 누적되므로 경고까지 걸리는 실제 시간은 영상 처리 속도에 따라 달라집니다.

### 영상 분석과 화면 구성 분리

`detector_logic.py`에서 사람·얼굴·물체를 분석하고, 감지 상태와 경고 이미지를 관리합니다. `app.py`는 카메라 영상을 분석 코드로 전달하고 결과를 웹 화면에 표시합니다.

웹 화면에는 시작·종료 버튼, 실시간 영상, 학생 ID 목록, 경고 알림을 배치했습니다. 출석·이탈 기록은 별도 탭에서 저장된 이미지를 확인하고 삭제할 수 있도록 구성했습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| [app.py](app.py) | Streamlit 화면, 카메라 연결, 대시보드와 경고음 |
| [detector_logic.py](detector_logic.py) | 모델 로딩, 행동 감지, 점수 누적, 이미지 기록 |
| [yolov8n-pose.pt](yolov8n-pose.pt) | 사람 영역과 자세 특징점 감지를 위한 모델 가중치 |
| [beep.wav](beep.wav) | 새 경고가 발생했을 때 사용하는 음원 |

실행 중 `temp_images/`와 `escape_images/` 폴더가 생성됩니다. `temp_images/`에는 출석으로 표시할 이미지와 경고 이미지가 저장되고, 이탈로 처리된 출석 이미지는 `escape_images/`로 이동합니다.

## 실행 방법

Python 환경에 다음 패키지가 필요합니다.

```text
streamlit
streamlit-webrtc
av
numpy
opencv-python
ultralytics
mediapipe
```

원 개발환경의 패키지 버전 목록은 저장되어 있지 않습니다. 특히 얼굴 분석 코드는 `mp.solutions.face_detection`과 `mp.solutions.face_mesh`를 사용하므로, 해당 API를 제공하는 MediaPipe 환경이 필요합니다.

휴대전화·모자 감지에는 `yolov8s-world.pt`도 필요합니다. 이 파일은 현재 저장소에 포함되어 있지 않으며, 모델을 자동으로 내려받을 수 없는 환경에서는 별도로 준비해 `app.py`와 같은 폴더에 배치해야 합니다. 해당 모델을 불러오지 못하면 코드상 휴대전화·모자 감지는 비활성화됩니다.

저장소를 내려받은 뒤 아래 명령으로 실행합니다. 코드와 모델·음원 파일이 같은 작업 폴더에 있도록 먼저 이동합니다.

```bash
cd classroom-monitoring
python -m streamlit run app.py
```

브라우저에서 카메라 접근을 허용한 뒤 **프로그램 시작**을 누릅니다. 경고음 재생은 브라우저의 자동 재생 설정에 영향을 받을 수 있습니다.

## 확인 범위

얼굴의 가림, 조명, 촬영 거리와 인물의 이동에 따라 감지 및 ID 유지 결과가 달라질 수 있습니다. 현재 저장소에는 별도의 성능 평가 데이터와 측정 기록이 포함되어 있지 않습니다.
